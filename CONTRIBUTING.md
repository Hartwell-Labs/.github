# Contributing to Hartwell Labs

Thanks for taking the time to contribute. This document applies to every
repository in the [Hartwell Labs](https://github.com/Hartwell-Labs)
organization.

## Ground rules

- Be respectful. See [`CODE_OF_CONDUCT.md`](./CODE_OF_CONDUCT.md).
- **Every feature ships with tests.** A pull request without tests will be
  asked for tests before it is merged.
- Keep changes focused. One logical change per pull request.
- Match the existing style. Run the project's `fmt` and `lint` targets before
  pushing.

## Getting started

1. Fork the repository and create a branch off the default branch
   (`feat/<topic>`, `fix/<topic>`, `docs/<topic>`).
2. Make your change, add tests, update documentation if behaviour changed.
3. Make sure the full test suite is green locally.
4. Open a pull request and fill in the template.

## Developer Certificate of Origin

By contributing you certify that you wrote the contribution, or have the right
to submit it under the project's licence (MIT unless stated otherwise). Sign
off your commits:

```
git commit -s -m "feat: add thing"
```

## Security

Never open a public issue for a vulnerability — follow
[`SECURITY.md`](./SECURITY.md) instead.

## Code of conduct

Participation in this project is governed by our
[Code of Conduct](./CODE_OF_CONDUCT.md). Report unacceptable behaviour to
contact@hartwell-labs.pl.

## Questions

Not sure where to start? Open a discussion or email
[contact@hartwell-labs.pl](mailto:contact@hartwell-labs.pl).
